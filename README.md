# One Emoji, One Smile

Entry for [One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f) on make.fun.

The entry is exactly one emoji: 🤗 (hugging face).

## Why 🤗

The judge picks the emoji most likely to make a stranger smile, weighing
warmth at first glance, universality, and whether the pick feels chosen
rather than the default smiley — with no intimacy, sarcasm or flirtation
that would read oddly from a stranger.

- **Warm at first glance:** a smiling face with open arms — warmth offered.
- **Universal:** a hug reads the same across ages and backgrounds.
- **Chosen, not default:** not the first smiley that comes to mind (😊), but
  still instantly readable.
- **Right for a stranger:** friendly, not affectionate — unlike 🥰 (hearts)
  or 🫶 (a love gesture), it claims no intimacy.

## How it works

`main.ts` writes exactly `🤗` (one Unicode code point, no trailing newline)
to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
